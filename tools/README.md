# 无人机地面站软件使用说明

## 概述

本地面站软件包含两个主要工具：
- **drone_ground_station.py** - 实时地面站，用于监控无人机状态
- **data_player.py** - 数据回放工具，用于分析记录的飞行数据

## 功能特性

### 实时地面站 (drone_ground_station.py)

#### 主要功能
1. **实时姿态角显示** - 显示Roll、Pitch、Yaw角度
2. **3D姿态可视化** - 实时3D姿态显示
3. **遥控通道监控** - 显示0-8通道的遥控信号
4. **传感器数据显示** - 显示加速度计和陀螺仪原始数据
5. **数据记录** - 将飞行数据保存到CSV文件
6. **实时曲线绘制** - 姿态角变化曲线

#### 数据格式要求
地面站支持匿名科创二进制协议，这是您飞控使用的标准协议。

##### 支持的协议帧类型

1. **姿态角数据帧 (功能码 0x03)**
   - 格式: AA FF 03 07 [pitch_low] [pitch_high] [roll_low] [roll_high] [yaw_low] [yaw_high] [00] [SC] [AC]
   - 数据: pitch, roll, yaw (16位有符号整数，需要除以100得到浮点角度值)
   - 注意：数据顺序是 俯仰(pitch)、横滚(roll)、偏航(yaw)

2. **IMU原始数据帧 (功能码 0x01)**
   - 格式: AA FF 01 0D [acc_x_low] [acc_x_high] ... [gyro_z_low] [gyro_z_high] [shock_sta] [SC] [AC]
   - 数据: 加速度计三轴 + 陀螺仪三轴 (16位有符号整数) + 震动状态

3. **四元数数据帧 (功能码 0x04)**
   - 格式: AA FF 04 09 [q0_low] [q0_high] ... [q3_low] [q3_high] [00] [SC] [AC]
   - 数据: 四元数 (16位有符号整数，需要除以10000得到浮点数)

##### 示例数据帧

姿态角数据帧示例:
```
AA FF 03 07 F8 FF 0F 00 2D 00 00 4A 4C
```
这表示: Pitch=-8.0°, Roll=15.0°, Yaw=45.0°

IMU数据帧示例:
```
AA FF 01 0D EA 04 9E FC A8 40 19 00 F1 FF 0A 00 00 00 7C
```
这表示: Acc(1258, -866, 16552), Gyro(25, -15, 10)

### 数据回放工具 (data_player.py)

#### 主要功能
1. **数据文件加载** - 支持CSV格式数据文件
2. **数据播放控制** - 播放、暂停、停止、跳转
3. **变速播放** - 支持0.25x到4x速度播放
4. **数据统计** - 显示姿态角统计信息
5. **曲线分析** - 完整的姿态角变化曲线

## 使用方法

### 启动实时地面站

1. 打开终端，进入tools目录
2. 运行命令：
   ```bash
   python drone_ground_station.py
   ```

3. 配置串口参数：
   - 选择正确的COM端口（默认为COM8）
   - 设置波特率（默认为115200）
   - 点击"连接"按钮

4. 开始数据记录：
   - 点击"开始记录"按钮开始记录数据
   - 点击"停止记录"按钮停止并保存数据

### 使用数据回放工具

1. 启动数据播放器：
   ```bash
   python data_player.py
   ```

2. 打开数据文件：
   - 点击"打开数据文件"按钮
   - 选择之前记录的CSV文件

3. 播放控制：
   - "播放/暂停" - 控制播放状态
   - "停止" - 停止播放并回到开始位置
   - 拖动进度条可跳转到指定位置
   - 调整播放速度（0.25x到4x）

## 数据文件格式

### CSV文件结构

记录的CSV文件包含以下列：

| 列名 | 描述 |
|------|------|
| timestamp | 时间戳（秒） |
| roll | 横滚角（度） |
| pitch | 俯仰角（度） |
| yaw | 偏航角（度） |
| rc_ch0 - rc_ch8 | 遥控通道0-8的值 |
| acc_x, acc_y, acc_z | 加速度计三轴数据（g） |
| gyro_x, gyro_y, gyro_z | 陀螺仪三轴数据（°/s） |

## 故障排除

### 串口连接问题

1. **无法连接串口**：
   - 确认COM端口设置正确
   - 检查串口是否被其他程序占用
   - 确认波特率设置正确

2. **数据接收异常**：
   - 检查飞控发送的数据格式是否正确
   - 确认波特率匹配
   - 检查串口线连接是否稳定

### 显示问题

1. **中文显示异常**：
   - 确保系统安装了中文字体
   - 可以修改代码中的字体设置：
     ```python
     plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'Arial Unicode MS']
     ```

2. **图形显示异常**：
   - 尝试降低刷新率
   - 检查matplotlib版本是否兼容

### 性能优化

1. **CPU使用率过高**：
   - 减少历史数据长度（修改max_history值）
   - 降低刷新频率

2. **内存占用过大**：
   - 定期清理日志（已实现自动清理）
   - 减少数据记录时间
